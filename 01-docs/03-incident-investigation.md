# Incident Investigation

## Overview

This document explains the SOC investigation process followed after Microsoft Sentinel generated an incident for ransomware-like impact activity.

This file focuses on investigation, evidence review, IOC collection, and timeline analysis.

---

## Incident Overview

The ransomware-like impact activity triggered a Microsoft Sentinel incident from the custom analytics rule.

| Field | Value |
|---|---|
| Incident Name | Ransomware-Like Impact Activity Detected |
| Severity | High |
| Status | In Progress |
| Assigned To | SOC Analyst / Lab Owner |
| Affected Host | SOC-WIN01 |
| Affected User | SOC-WIN01\azureuser |
| Process | C:\Windows\System32\cmd.exe |

---

## Investigation Objective

The objective of the investigation was to answer the following SOC questions:

| Question | Finding |
|---|---|
| Which host was affected? | SOC-WIN01 |
| Which user executed the activity? | SOC-WIN01\azureuser |
| What process was used? | cmd.exe |
| What command-line activity was observed? | Ransomware-like impact command |
| What files were affected? | Test files with `.locked` extension |
| Was a ransom note created? | Yes, `ransom-note2.txt` |

---

## Evidence Reviewed

During the investigation, the following evidence was reviewed:

| Evidence Source | Purpose |
|---|---|
| Sentinel Incident Overview | Confirmed incident name, severity, owner, and status |
| Alert Details | Reviewed the alert generated by the analytics rule |
| Entities | Identified affected host and user |
| KQL Logs | Reviewed Event ID 4688 process creation logs |
| Endpoint File Path | Confirmed `.locked` files and ransom note |
| Investigation Timeline | Correlated attacker-like activity before impact |

---

## Investigation Timeline Query

```kql
SecurityEvent
| where TimeGenerated > ago(6h)
| where EventID == 4688
| where CommandLine has_any ("whoami", "ipconfig", "net user", "net localgroup", "schtasks", "cmdkey", "Ransomware-Simulation-Lab", ".locked", "ransom-note")
| project TimeGenerated, Computer, Account, NewProcessName, CommandLine, ParentProcessName
| order by TimeGenerated asc
```

## Timeline Findings

| Phase | Evidence |
|---|---|
| Discovery | `whoami`, `ipconfig`, `net user`, `systeminfo` commands observed |
| Persistence | `schtasks` command observed |
| Privilege Checking | `whoami /priv`, `whoami /groups`, administrator group checks observed |
| Credential Discovery | `cmdkey /list`, `net user`, and user directory listing observed |
| Impact | `.locked` extension and ransom note creation observed |

## Investigation Summary

The investigation confirmed ransomware-like impact behavior on `SOC-WIN01`.

The activity was executed through `cmd.exe` and involved file extension modification and ransom note creation. Earlier activity also showed discovery, persistence, privilege checking, and credential discovery behavior.

The incident was validated as a high-severity ransomware-like activity and moved to initial response.
